# nginx

This is nginx [engine x], an HTTP and reverse proxy server, a mail proxy server, and a generic TCP/UDP proxy server.

Documentation is available at http://nginx.org

## Archived 3rd-Party Fork

This repository is an archived fork of [`nginx/nginx`](https://github.com/nginx/nginx).
As part of Chef's effort to standardize our open source repositories, we are archiving this fork. 

If you are looking for the active nginx development, please visit the original repository:
https://github.com/nginx/nginx
